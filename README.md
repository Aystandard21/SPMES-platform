# SPMES - Student Project Management and Evaluation System

Final Year Project - Adeleke University, May 2026

A web-based platform to manage final year projects: topic submission, chapter uploads, supervisor feedback, approval tracking, and evaluation.

**Stack:** React (Frontend) + Node.js (Backend) + PostgreSQL via Supabase (Database/Auth)

**Features:**
- Role-based dashboards (Student, Lecturer, Admin)
- Project topic submission & approval
- Chapter-by-chapter upload & feedback
- Secure authentication & document storage
